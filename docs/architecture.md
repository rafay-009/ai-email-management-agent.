# Architecture and operations

Next.js forwards `/api/v1/*` to FastAPI so browser requests use one origin. The backend uses service functions for owner-scoped context, analysis persistence, drafts, and the approval state machine. The graph runs classification and conditionally drafts a reply. Structured provider results are validated and checked against source evidence. Every successful analysis and its extracted tasks commit together. A failed run keeps an error code and can be retried.

Send proposals hold an immutable canonical payload hash and an idempotency key. Draft edits increment the version and supersede pending approvals. Approving claims the draft and the pending proposal in a transaction, then executes the provider call. Provider timeout or stale execution produces an unknown outcome. Operators reconcile by checking Gmail and the audit log before composing another reply.

The browser owns navigation state. Manual sync fetches a bounded inbox snapshot, deduplicates provider IDs, and keeps rows omitted from partial results. Thread context uses locally synchronized mail. Analysis requests execute synchronously. Set gateway timeouts for model calls and sequential batches or keep batches small. The graph has two model nodes, one schema retry per node, and a bounded provider timeout. Production should use a separate database and HTTPS ingress. Set `APP_BASE_URL`, `API_BASE_URL`, `CORS_ORIGINS`, and the exact Google callback URL. For an externally routed backend, set `INTERNAL_API_URL` before building the frontend.

The PostgreSQL URL format is `postgresql+psycopg://user:password@host/dbname`. Apply migrations once before starting multiple replicas. Back up the database and retain the encryption key in a separate secrets manager. Restore them together for recovery. Before migration, stop writers and take a SQLite backup or a PostgreSQL snapshot. Roll back application code and restore the snapshot if needed. Alembic downgrade drops the tables in the initial migration and is suitable for disposable databases.
